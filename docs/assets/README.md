# Leaf identity

The [Leaf logo](leaf-logo.png) pairs an organic leaf with a rounded, friendly
wordmark. It reflects the project's aim of making local CPU inference accessible.

The asset is a transparent PNG, generated with the built-in image-generation
tool and reviewed for the README. It is a raster logo concept, not an editable
SVG master. Preserve the aspect ratio and clear space around the mark.

## Design brief

The selected direction was **an organic leaf with a warmer, friendlier wordmark**.

Initial prompt:

> Create an original horizontal logo for the open-source CPU inference project
> named “Leaf”. Use exactly “Leaf” and no other text. Pair a simple organic leaf
> silhouette with a flowing negative-space vein and a warm, softly rounded
> humanist wordmark. Use flat botanical greens, generous margins, and a compact
> horizontal composition with the mark left and wordmark right. Keep a genuine
> transparent background. Avoid mockups, scenery, borders, shadows, circuitry,
> gradients and additional taglines. Keep the silhouette recognizable at small sizes.

Refinement prompt:

> Preserve the leaf shape, composition, margins and exact wordmark. Clean the
> rendering, negative-space vein and contours; remove speckles and mottled texture.
> Use a fresh green leaf and a medium botanical green wordmark readable on white
> and charcoal. Keep the transparent alpha background and add no other artwork.

Both steps used the built-in tool, not the API/CLI fallback. The source concept
was retained outside the repository; the selected asset is stored here so the
README does not depend on a local generation cache.
